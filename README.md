# 🎵 Mini Reproductor MP3 (Desktop)

Un reproductor de música ligero y minimalista desarrollado para escritorio en Python, enfocado en el consumo eficiente de recursos y una interfaz clásica sin complicaciones.

## 🚀 Características

- 📁 **Selección de directorio:** Carga colecciones locales de música (.mp3).
- 🔍 **Búsqueda en tiempo real:** Filtrado rápido de canciones por nombre.
- 🔀 **Modos de reproducción:** Soporte para modo aleatorio (Shuffle) y reproducción secuencial.
- ⚡ **Interfaz ligera:** Carga rápida e impacto mínimo en memoria RAM.

## 🛠️ Tecnologías utilizadas

- **Lenguaje:** Python 3
- **GUI:** Tkinter / CustomTkinter
- **Audio Engine:** Pygame (mixer)
